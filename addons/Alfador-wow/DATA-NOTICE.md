Polestar Forever database release 2026.11.1
https://github.com/fitzforge/polestar/releases/tag/data-v2026.11.1

QuestCatalog.lua is an Alfador projection of quest titles and pickup/turn-in
entity names. It is generated from the GPL-3.0-only database tables. The
original tables, schemas, licenses and credits are in the archive's
Polestar-source directory alongside the generator. The database source build
is 1.60.1.70532. Blizzard names and titles retain their original rights.
